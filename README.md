This personal website is my final individual project for MMS 171. Over the term, it grew from a simple HTML profile into a responsive portfolio that reflects who I am as a math teacher, BAMS student, and someone who enjoys making creative ideas easier to understand.

## Featured projects

### 12 Principles of Multimedia Design

An educational presentation created on August 28, 2026. I wanted to explain the principles in a way that audiences could easily follow, combining clear information and thoughtful visual design.

The video is embedded directly in the profile, and the original presentation is also available in [Canva](https://canva.link/8o1uzosjwnfg9px).

### Whisker & Wonder

A collaborative website completed on November 18, 2026, for an animal-inspired T-shirt brand that promotes kindness toward stray and rescued animals. As group leader and main coder, I designed the homepage, privacy policy page, and mobile layouts with accessibility in mind, and guided my groupmates as we built the site together. It was my first time truly exploring coding, so seeing our shared ideas become a functioning website made me especially proud.

A compact homepage preview is embedded in my portfolio beneath the project description. Visitors can explore the entire website using the project link.

[Visit Whisker & Wonder](https://rfmoreno1.github.io/Whisker-and-Wonder/)

## Design and development

- Semantic HTML5 for clear structure and meaningful headings.
- External CSS with Flexbox, rem units, and a mobile media query.
- Playfair Display for expressive headings and Nunito Sans for comfortable body text, with web-safe fallbacks.
- A warm cream and muted rose palette, generous spacing, and consistent typography.
- Descriptive links, image alternative text, keyboard focus indicators, and a skip navigation link.
- Subtle CSS hover transitions for navigation, project, and contact links, with reduced-motion support.
- Matching, responsive media previews: the embedded multimedia video and the Whisker & Wonder homepage.
- [Canva typography style guide](Typography%20style%20guide%20flyer.png) retained as a repository reference for Module 7.
- Well-formed XML to document the project archive.

## Opening the website

Download the repository files into the same folder and open `index.html` in a browser. An internet connection is needed to load Google Fonts and visit external projects.

Useful review tools: [W3C HTML Validator](https://validator.w3.org/), [W3C CSS Validator](https://jigsaw.w3.org/css-validator/), and [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/).
